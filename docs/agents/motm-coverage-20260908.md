## Selection precedence

1. Explicit editorial official/media/AM4 selection, including later paragraphs.
2. Reviewed AM4 editorial choice, scoped to the exact report ID.
3. For other finished reports, an optional AM4 data-based choice using provider
   player ratings; equal ratings use goals + assists, then minutes. Complete ties
   and substantially incomplete or one-team data produce no automatic selection.

Existing positive award statements that cannot be parsed block automatic choices.
Missing/ambiguous player identity never receives a guessed portrait. A failed
optional data request cannot hide the report. Fetching is coalesced with lineup
insights for the same fixture and does not refresh the whole overview.
